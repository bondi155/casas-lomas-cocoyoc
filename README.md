# Casas · Lomas de Cocoyoc

Mini app React + MUI optimizada para celular.

## Funciones
- Tarjetas con foto, precio, vendedor y publicación.
- WhatsApp y llamada separados.
- Editar cualquier propiedad tocando el lápiz.
- Agregar propiedades con el botón +.
- Favoritos.
- Filtro por vendedor y buscador.
- Los cambios quedan guardados en `localStorage` del navegador.

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Publicar
Funciona directamente en Vercel o Netlify como proyecto Vite.
Build command: `npm run build`
Output directory: `dist`
